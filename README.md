# 🚗 Used Car Price Prediction

## 📌 Overview

This project builds a machine learning model to predict the selling price of used cars based on vehicle and seller-related attributes.

Multiple regression models are compared, followed by hyperparameter tuning of XGBoost to improve prediction performance.

The project also includes a Flask web application for making used-car price predictions.

---

## 🎯 Objective

- Analyze used-car pricing data.
- Perform data preprocessing and feature engineering.
- Encode categorical variables.
- Compare multiple regression models.
- Tune the best-performing model.
- Save the trained model and preprocessing objects.
- Deploy the prediction model through a Flask application.

---

## 📊 Dataset

The project uses a used-car dataset containing information such as:

- Car brand
- Fuel type
- Vehicle-related attributes
- Selling price
- Other car and seller information
